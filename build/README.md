# Royal Linux Build Infrastructure

This directory contains the infrastructure used to build Royal Linux.

## Goals

- Build packages from documented recipes.
- Automate dependency resolution.
- Produce reproducible build outputs.
- Support x86_64 and ARM64.
- Build Royal installation images.
- Maintain separate testing and official build pipelines.

## Long-Term Direction

Royal Linux should eventually maintain its own independent build infrastructure rather than relying on another distribution's build system.

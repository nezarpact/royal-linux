# Royal Linux Packages

This directory contains package recipes and definitions for the Royal Linux package ecosystem.

## Goals

- Maintain official package recipes.
- Define package dependencies and build requirements.
- Support binary and source-based packages.
- Support configurable package features.
- Integrate with the Pact package manager.
- Organize packages into maintainable collections.

## Package Sources

Official package recipes will be maintained in Royal-controlled Git repositories.

All official packages must pass the Royal testing and verification process.

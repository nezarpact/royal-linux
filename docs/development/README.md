# Royal Linux Development

This directory documents the development workflow and contribution process.

## Development Environment

- Linux development host
- Git for version control
- VSCodium for editing
- GitHub for source control and collaboration

## Workflow

1. Develop changes in dedicated branches.
2. Test changes before merging.
3. Document significant architectural decisions.
4. Review changes before integration.
5. Keep the main branch stable.

## Development Priorities

- Maintain clear project documentation.
- Keep components modular.
- Automate repetitive tasks.
- Test changes before official integration.
